How to keep this current

Two commands rebuild most of this table from scratch, in case it drifts:

git log --diff-filter=A --name-only --all --pretty=format:"%h %ad %s" --date=short
git log --diff-filter=D --name-only --all --pretty=format:"%h %ad %s" --date=short

One blind spot worth remembering: anything proxied by a Render rewrite rule, like TaktStack, is invisible to git entirely. The Render dashboard is the only record of those.
